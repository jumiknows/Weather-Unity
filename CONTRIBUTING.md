# Contributing

Weather Unity is a small prototype. Keep changes focused and easy to verify in the pinned Unity editor.

## Setup

Use Unity `6000.4.7f1` and open:

```text
Assets/Scenes/GetStarted_Scene.unity
```

## Before opening a pull request

1. Open the project without Unity upgrade prompts.
2. Enter Play Mode and test the behavior you changed.
3. Check the Console for new errors.
4. Do not commit generated Unity folders such as `Library`, `Temp`, `Logs`, or IDE project files.
5. Include a screenshot or short recording for visible changes when useful.

Use clear titles such as:

```text
fix: reset player after falling out of bounds
feat: add weather transition control
docs: clarify scene setup
```

Do not add third-party assets unless their license permits redistribution in this repository.
